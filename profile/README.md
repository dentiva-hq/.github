# Dentiva

Dentiva is a cloud-based dental practice management and clinical EMR platform built for dental clinics in India.

## What we build

- Interactive FDI odontogram for adult and pediatric charting
- Automated WhatsApp appointment confirmations and reminders
- Chairside GST invoicing with dynamic UPI QR payments
- Digital case sheets, e-prescriptions and radiograph storage
- Clinic website builder with online booking

## Tech stack

Next.js, React, TypeScript, Tailwind CSS, Supabase, PostgreSQL, Cloudflare Workers, WhatsApp Cloud API
